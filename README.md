Waxy Player
Современный и эстетичный веб-музыкальный плеер с тёмным оформлением в чёрно-золотой палитре, процедурной генерацией треков, анимированным винилом и интеллектуальной системой рекомендаций.

Функционал
Интерактивный проигрыватель с анимацией вращения виниловой пластинки

Синхронизированные субтитры с эффектом караоке

Каталог из 50 уникальных треков в различных жанрах (Lo-Fi, Synthwave, Cyberpunk, Hip-Hop)

Алгоритм персональных рекомендаций на основе истории прослушиваний

Поддержка загрузки пользовательских фоновых изображений

Интерактивный поиск и фильтрация треков по категориям

Технологический стек
Проект разработан с использованием нативных веб-технологий без применения сторонних библиотек и фреймворков:

HTML5

CSS3 (Flexbox, Grid, CSS Variables)

Vanilla JavaScript (ES6+, Web Audio API, LocalStorage)
